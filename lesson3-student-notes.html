Notes: Solving a System by Elimination

Read these steps. You'll use them for every example below.

  1. Make sure each equation is in standard form (Ax + By = C).
  2. If necessary, multiply one or both equations by a number so that the coefficients of a chosen variable are opposites (like 3y and −3y).
  3. Add the equations. The chosen variable cancels out (is eliminated).
  4. Solve for the remaining variable.
  5. Substitute that value into one of the original equations to find the other variable.
  6. Check the solution in both original equations.
